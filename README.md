# Terraform Infrastructure as Code Project

Infrastructure provisioning using Terraform with Docker provider,
demonstrating Infrastructure as Code principles.

## Features

- Terraform Docker provider setup
- Automated nginx container provisioning
- Infrastructure state management
- Destroy and recreate with one command
- Idempotent infrastructure definitions

## Tech Stack

- Terraform — Infrastructure as Code
- Docker — Container runtime
- nginx — Web server

## How to Run

terraform init
terraform plan
terraform apply

Navigate to http://localhost:8080 to see the running infrastructure.

## Key Concepts Learned

- Infrastructure as Code principles
- Terraform state management
- Provider configuration
- Resource dependency management
- Idempotent deployments
